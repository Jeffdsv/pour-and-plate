# Pour & Plate 🍷🍺🍽️

A personal tasting journal for wine, beer and restaurants. Log what you drink and eat, rate it, see it on a map, and get recommendations based on your own taste.

> **Status:** Work in progress. Built step by step as a portfolio project.

## Features (planned)

- Log wines, beers and restaurant visits with rating, notes, price and date
- Browse and search your tasting history
- Restaurant map based on OpenStreetMap data
- Taste profile and statistics (favourite grapes, beer styles, regions, spend)
- Recommendations: "you liked X, try Y"
- Ranked lists using a Bayesian average
- Installable on your phone (PWA)
